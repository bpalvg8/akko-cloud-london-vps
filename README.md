规律很清晰：电信最慢，广东和四川两个南方省份垫底；联通居中；移动最快，北京移动 140ms 是全表最低。原因在线路走向上。

**去程**：电信、联通走 CN2 GIA，移动走 CMIN2。

**回程**：移动走 CMIN2，电信和联通走 CTG / CN2 GIA。

这里要纠正一个流传很广的说法。有些测评把 AkkoCloud 三个机房概括成“全线 CN2 GIA”，这个表述对电信、联通成立，对移动不成立。移动的去程和回程都是 CMIN2（中国移动自己的国际精品网），并不是电信的 CN2 GIA。CMIN2 本身质量不差，移动用户实测到的 140–188ms 也确实是三家里最好的，但把它叫成 GIA 会让人对线路归属产生误判，尤其是你在做多运营商分流的时候。

对实际使用的影响：电信用户看到的延迟最高，但 CN2 GIA 回程在晚高峰的抖动通常比普通线路小，这正是它的价值所在。移动用户延迟最低，走的是 CMIN2 这条相对新的通道。

## 实测性能与带宽：标称 500Mbps 不等于国内能跑满

2025 年 6 月 13 日，第三方 NodeQuality 对伦敦 KVM-CN2-A1 mini 做过一次完整测试，配置是 1 核 Intel Broadwell（2494MHz）、512MB 内存加 1GB Swap、Debian 12、IPv4 在线 IPv6 离线，ISP 记录为 Kirino LLC（AS41378），托管在 HK CEDOC LIMITED，位置伦敦。这组数据是判断这台机器底子的最直接依据。

**CPU**：Geekbench 5 单核 413、多核 413（单核单线程，两个数字相同是正常的），SysBench 单核 660 分。这个水平够跑轻量服务、静态站点、代理转发，跑带插件的中型 WordPress 会吃力。

**磁盘**：4k 小块读写约 44MB/s，64k 以上到 1m 稳定在 520–556MB/s。小块性能一般，大块读写是正常的 SSD 水准。小文件密集的操作（比如大量 PHP 会话）不会特别快，正常建站够用。

**内存带宽**：单线程读 15276.50MB/s、写 7977.63MB/s，没有异常。

**带宽是重点。** 套餐标称 500Mbps，但同一份报告里的 iPerf3 单线程测试显示：本地单线程 TCP 跑不到 500Mbps 峰值，回中国的 TCP 只有约 100Mbps。另一份整理提到伦敦“实测下载速度最高可达 60Mbps 左右”。

这几个数字不矛盾，它们描述的是不同环节：端口速率是上限，单线程 TCP 受协议和线路影响达不到上限，跨境单线程再打一层折扣。实际含义是，你要拿这台机器跑满 500Mbps，得靠多线程并发；单线程大文件传输，国内方向按 100Mbps 左右预期比较现实。前排文章里“500Mbps 带宽”这句话很容易被读成“国内能跑 500M”，这是最容易产生的预期落差。

如果需要更大带宽，A2 mini 及以上标称 1Gbps，端口上限更高，但跨境单线程的瓶颈依然存在。

**不能以“不是原生 IP”为由退款。** 官方 TOS 明确写了这一条。如果你的业务强依赖原生 IP（比如某些地区的账号注册、特定平台的运营），下单前先想清楚。

## 适合谁，不适合谁

**适合**：

- 需要英国 IP 落地，但访问方主要在国内
- 业务面向欧洲用户，需要一个欧洲节点做补充
- 做多机房部署，伦敦是其中一环
- 能接受 150–200ms 延迟，看重的是回程质量和晚高峰稳定性
- 预算卡在年付 ¥299 这个门槛上，只需要一台轻量机器

**不适合**：

- 把低延迟当第一需求。圣何塞约 150–168ms，比伦敦低一档，同样的预算在美西能拿到更低的 ping。
- 需要国内单线程跑满几百 Mbps。跨境单线程大约 100Mbps，这不是这台机器的问题，是链路物理条件。
- 强依赖原生 IP，或者需要保证 IP 与测试 IP 同网段。
- 需要明确退款保障。退款条款的公开说法互相冲突，不能把它当安全网。

如果你的场景落在“不适合”里，选择其实很直接：要低延迟就看圣何塞机房，要便宜年付就看普通线路的机器，别为了“英国”两个字多付线路溢价。

## 常见问题

**伦敦和圣何塞怎么选？**
延迟优先选圣何塞，公开数据在 150–168ms 区间，比伦敦低 30–50ms。需要英国 IP、欧洲业务落地、或者要做多地区节点，选伦敦。两个机房回程都做了优化，线路质量不是决定因素，地理位置才是。

**A1 mini 到底是 512MB 还是 768MB？**
三个数字都出现过：512MB、768MB、0.9GB。2025 年 6 月的实测机器系统内显示可用 464.9MiB，对应标称 512MB。另外两个数字可能来自不同批次或页面改版。下单页写多少算多少，买之前看清楚，别按测评里的数字做容量规划。

**年付能不能退？**
公开资料给出三种互相冲突的说法：TOS 严格不退、24–48 小时窗口、无退款政策且只退余额。我无法确认当前生效的是哪一条。年付前先按月付或季付（¥99/季）跑一段时间，是唯一可靠的规避方式。

**优惠码能叠加吗？**
不能。第三方整理的规则明确写了同一订单只能用一个大优惠码。AKKO15、NEW2026、VPS20 这些码本身也未在官网核验，结账页试出来才算数。

**500Mbps 能跑满吗？**
端口上限是 500Mbps，但本地单线程 TCP 打不到峰值，回中国单线程约 100Mbps。多线程并发能接近端口上限，单线程大文件传输按 100Mbps 预期。

**这台机器能解锁流媒体吗？**
公开测评提到欧美方向的解锁能力不错，但 IP 不保证原生、不保证与测试 IP 同网段，解锁结果取决于分到的 IP。拿到机器自己测，别按别人的结果预期。
